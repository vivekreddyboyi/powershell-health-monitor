# PowerShell Health Monitor

## Overview

This project automates Windows service health monitoring using PowerShell.

It retrieves all Windows services, displays their status, and exports the results into a CSV report for operational monitoring.

## Features

- Monitor Windows services
- Export service status to CSV
- PowerShell automation
- Easy to customize
- Enterprise-ready folder structure

## Requirements

- Windows
- PowerShell 5.1 or later

## Run

```powershell
.\scripts\HealthCheck.ps1
```

## Output

HealthReport.csv
