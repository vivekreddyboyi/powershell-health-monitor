## Overview

PowerShell Health Monitor is a lightweight automation project that monitors Windows services, generates health reports, and exports service status to CSV. The project demonstrates scripting, automation, and operational monitoring concepts commonly used in DevOps environments.

---

## Features

- Monitor Windows services
- Export health report to CSV
- PowerShell automation
- Easy to customize
- Enterprise-style folder structure
